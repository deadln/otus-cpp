# bayan - утилита для поиска дубликатов

```bash [аргументы]
bayan
```

## Аргументы командной строки

**-h, --help** - вызов справки
<br>
**-i, --input** - список директорий для проверки, по умолчанию проверяет текущую папку
<br>
**-e, --exclude** - список директорий, исключаемых из проверки
<br>
**-d, --depth** - глубина проверки поддиректорий, по умолчанию 0
<br>
**-m, --min_size** - минимальный размер файла для проверки в байтах, по умолчанию 1 байт
<br>
**-s, --size** - размер блока для сравнения в байтах, по умолчанию 1 байт
<br>
**--mask** - маска для файлов для провеки, составляется по правилам boost::regex
<br>
**--hash** - алгоритм для хэширования (С++ std::hash(по умолчанию) или md5)
<br>
